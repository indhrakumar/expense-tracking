# 💸 Xpense - Expense Tracker

A modern and responsive Expense Tracker web application built using **HTML, CSS, and JavaScript**. Manage your income and expenses efficiently with a clean dashboard, category tracking, transaction history, and Dark/Light mode support.

---

## 🚀 Features

### 💰 Dashboard Overview
- Total Balance Tracking
- Total Income Display
- Total Expense Display
- Monthly Expense Summary
- Transaction Count
- Top Spending Category

### ➕ Transaction Management
- Add Income Transactions
- Add Expense Transactions
- Category Selection
- Date Selection
- Real-time Balance Updates
- Delete Transactions

### 📊 Expense Analytics
- Category-wise Expense Breakdown
- Dynamic Progress Bar
- Top Spending Category Detection
- Expense Summary Cards

### 📜 Transaction History
- Search Transactions
- Filter by Type
- Filter by Category
- View Transaction Dates
- Delete Existing Records

### 🌗 Theme Support
- Dark Mode
- Light Mode
- Smooth Theme Switching



### 📱 Responsive Design
- Desktop Friendly
- Tablet Friendly
- Mobile Friendly

---

- HTML5
- CSS3

## 🎯 How To Use

1. Choose Transaction Type (Income / Expense)
2. Enter Description
3. Enter Amount
4. Select Category
5. Choose Date
6. Click **Add Transaction**
7. View Updated Dashboard Statistics
